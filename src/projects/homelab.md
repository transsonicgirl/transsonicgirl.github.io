I run a lot of services I use daily on a server in my apartment! This has been a really fun project that's taught me a lot about networking, systems administration, and security. A few of the things I host include Home Assistant, Plex, Pi-hole (for local DNS firewall), and NAS/backup services. All of this is declaratively managed on NixOS, which makes deployments & recovery super convenient.
