# Personal Website

This is the project code for my personal site. Everything is written in Astro with supplemental HTML/CSS/JS. The website is broadly designed with reusable page layouts coded in Astro and repeated components (e.g. blog posts, project cards) written in markdown. These markdown files are then fed through standardized layouts that generate the appropriate page styling for each. Astro's [documentation](https://docs.astro.build/en/getting-started/) is a great resource for learning more about this, and Astro in general is really well suited for static webpages like this.
